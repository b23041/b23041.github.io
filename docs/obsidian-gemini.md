# 옵시디언(Obsidian) + Gemini CLI 연동 가이드

이 문서는 옵시디언(MD파일 정리) 환경에서 터미널을 열고, Google의 Gemini CLI를 호출하여 설계기준 등의 문서를 빠르게 검색하고 질의응답하는 환경을 구축하는 방법을 안내합니다.

---

## 1. Gemini-CLI 환경 조성

### 1-1. API Key 발급 및 시스템 환경 변수 등록
Gemini를 사용하기 위해 먼저 Google API Key를 발급받고 내 컴퓨터의 환경 변수로 등록해야 합니다.

1. 키보드의 `WIN키`를 누르고 검색창에 **시스템 환경 변수 편집**을 입력하여 실행합니다.
2. [시스템 속성] 창의 하단에 있는 **[환경 변수(N)...]** 버튼을 클릭합니다.
3. [환경 변수] 창의 하단 **시스템 변수(S)** 영역에서 **[새로 만들기(W)...]**를 클릭합니다.
4. 아래와 같이 입력하고 **[확인]**을 누릅니다.
   - **변수 이름(N):** `GOOGLE_API_KEY`
   - **변수 값(V):** `(발급받은 구글 Gemini API 키)`
5. 열려있는 모든 창의 [확인]을 눌러 설정을 저장합니다.

### 1-2. 터미널 명령어로 바로 묻고 답하기 (공식 CLI 도구 설치)
1. **사전 준비**: 컴퓨터에 `Node.js`가 설치되어 있어야 합니다.
2. **설치 명령어**: `cmd`(명령 프롬프트)를 열고 아래 명령어를 입력합니다.
   ```bash
   npm install -g @google/gemini-cli
   ```
3. **설치 후 체크**: 아래 명령어를 입력하여 제미나이 CLI의 사용 설명서(옵션 목록 등)가 화면에 출력된다면 정상적으로 설치된 것입니다.
   ```bash
   gemini --help
   ```
4. **API 키 작동 및 질의응답 테스트**: 실제로 질문을 던져서 답변이 오는지 확인합니다.
   ```bash
   gemini "안녕? 너에 대해 짧게 소개해 줘."
   ```
   > **초기 설정 주의사항**
   > 처음 실행 시 옵션을 선택하는 화면이 나올 수 있습니다. 키보드 방향키(↓)를 이용해 초록색 하이라이트를 이동시켜 **`Trust folder (User)`** 또는 **`Use Gemini API Key`** 등을 상황에 맞게 선택해 줍니다.

## 2. 옵시디언 내부 환경설정

cmd 창에서 제미나이 CLI가 완벽하게 작동하는 것을 확인하셨으니, 이제 옵시디언 내부로 이 환경을 그대로 가져올 차례입니다.

### 2-1. 옵시디언에 커뮤니티 플러그인 설치
1. 옵시디언 좌측 하단의 **톱니바퀴 아이콘(설정)**을 클릭합니다.
2. 좌측 메뉴에서 **커뮤니티 플러그인(Community plugins)** 항목을 선택합니다.
3. 만약 '제한 모드(Restricted mode)'가 켜져 있다면, 보안 경고 아래의 **[제한 모드 해제(Turn off)]** 버튼을 눌러 플러그인 설치를 허용합니다.
4. 플러그인 **탐색(Browse)** 버튼을 누르고 검색창에 `Termy`를 정확히 입력합니다.
5. 검색 결과에서 **Termy**를 클릭한 후 **[설치(Install)]** 버튼을 누릅니다.
6. 설치가 완료되면 동일한 위치에 나타나는 **[활성화(Enable)]** 버튼을 반드시 클릭하여 플러그인을 켭니다.

### 2-2. 옵시디언에서 터미널을 열고 제미나이 활용하기
1. 키보드에서 `Ctrl + P`를 눌러 **명령어 팔레트**를 엽니다.
2. 입력창에 `Termy`를 치고, 목록에서 **`Termy: Open Terminal`**(또는 `Toggle Terminal`)을 찾아 마우스로 클릭하거나 엔터를 칩니다.
3. 옵시디언 화면 하단이나 측면에 cmd와 똑같은 역할을 하는 까만색 터미널 프롬프트 창이 나타납니다.
4. 까만색 터미널 프롬프트 창에 `gemini`를 입력하고 초록색으로 빛나는 **`1. Trust folder`**를 선택하고 엔터를 누릅니다. (권한 부여 과정)
5. 제미나이 로고가 뜨면서 커서가 깜빡이는 대화형 모드로 진입하면, 키보드에서 `Ctrl + C`를 누르거나 입력창에 `/exit`을 치고 엔터를 눌러 제미나이를 종료합니다.

### 💡 활용 팁: 명령어 옵션(`-p`)의 차이
상황에 따라 두 가지 방식으로 질의응답을 진행할 수 있습니다.

* **`-p`를 빼고 쓸 때 (대화형 모드)**
  ```bash
  gemini "설계기준에 대해 알려줘"
  ```
  계속해서 대화를 이어나갈 수 있는 전용 챗봇 창(대화형 모드)이 열립니다. 답변이 끝나도 프로그램이 켜져 있으므로, 사용자가 직접 종료 명령어(`/exit` 또는 `Ctrl + C`)를 입력하기 전까지는 원래의 기본 프롬프트 화면으로 돌아가지 않습니다.

* **`-p`를 넣고 쓸 때 (단답형 모드)**
  ```bash
  gemini -p "설계기준에 대해 알려줘"
  ```
  명령어 뒤에 입력한 내용을 일회성 질문(Prompt)으로 인식하여 결과값만 화면에 텍스트로 출력합니다. 그 후 곧바로 제미나이 작동을 종료하고 원래의 프롬프트 화면으로 깔끔하게 복귀합니다.
